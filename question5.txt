Question Title: Execute a Python Script Directly
Question Link: https://my.newtonschool.co/playground/code/mepmefz373b4?lecture_hash=t5qc0u6ap8tg
Solution:
    cat << 'EOF' > hello.py
    #!/usr/bin/env python3
    print('Hello from Python')
    EOF
    chmod +x hello.py
    ./hello.py

Approach:
    1. I used Herodoc and Shebang line to write the code
    2. Gave the hello.py the executable permissions
    3. I ran the hello.py without python3 explicity

Result: The code ran successfully and got the output "Hello from Python"
