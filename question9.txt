Question Title: Build Pipeline Directory Tree
Question Link: https://my.newtonschool.co/playground/code/r2ui5gw5lhqt?lecture_hash=n9ynhcuvkld8
Solution:
    mkdir -p pipeline/stages/build
    mkdir -p pipeline/stages/test/unit/integration
    mkdir -p pipeline/env/staging
    mkdir -p pipeline/env/prod
    mkdir -p pipeline/artifacts/old

    chmod 750 pipeline/stages
    chmod 770 pipeline/artifacts
    chmod 700 pipeline/env

    cd pipeline/stages/build/
    touch app.py config.json NOTES.md
    echo "Build stage initialized." > NOTES.md

    cd ../..
    cd artifacts/old/
    touch build.log test.log deploy.log
    chmod 640 build.log test.log deploy.log

Approach:
    1. I used -p in mkdir to create the parent folder if they were missing
    2. The Question was straight forward. I just did what the steps to follow in the Question said
    3. I used chmod to change the permissions for the files and folder as per the question's requirement

Result: All the files were organized in the correct order and the permissions are changed correctly
